# EIGA — Economic Intelligence and Governance Analytics

**An interactive data visualization platform for exploring India's socioeconomic landscape, economic performance, and governance indicators.**

EIGA is a dashboard designed to present the relationships between key socioeconomic indicators, including GDP growth, unemployment, poverty, tax revenue, financial market stability, healthcare, education, and data governance.

By combining interactive visualizations with contextual information, EIGA aims to make complex economic and public policy concepts easier to explore, interpret, and communicate.

### Key Features

- **Interactive indicator network:** Explore eight interconnected socioeconomic domains.
- **Contextual information panels:** Examine indicator-specific statistics and India-focused narratives.
- **Dynamic visualizations:** Animated network connections, particle effects, and interactive visual elements.
- **Economic and governance perspective:** Organizes indicators across economic performance, financial stability, public services, and digital governance.
- **Custom dashboard interface:** A dark, modern visual design with distinctive gradients and interactive effects.

### Technology Stack

- HTML5
- CSS3
- JavaScript
- HTML Canvas API

### Objective

To create an accessible and visually engaging interface for exploring economic and governance indicators and communicating complex socioeconomic information through interactive data visualization.

### Future Scope

- Integrate verified economic and socioeconomic datasets.
- Add statistical analysis and correlation studies.
- Develop and evaluate machine learning models for economic forecasting.
- Introduce interactive filters, historical trends, and evidence-based policy insights.

**Implementation note:** The current dashboard uses predefined indicator values and written projections. Live data integration and machine learning forecasting are planned extensions, not currently implemented features.
